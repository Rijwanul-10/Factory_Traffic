## 2. Summary of Missing Items to Implement
1. **Sensor Offline & Direction DEGRADED Handling (Spec §9 & Phase 2 #9):**
   - Ability for a directional sensor to report OFFLINE.
   - Marks that direction as DEGRADED.
   - Enforces a minimum fixed-time service allocation for the degraded direction during automatic cycle.
2. **10,000 Step Randomized Safety Invariant Test (Phase 2 #1):**
   - Exhaustive test verifying that across 10,000 random actions (arrivals, clearances, manual requests, emergencies, ACKs, timeouts, ticks), conflicting phases never receive GREEN simultaneously, no GREEN -> conflicting GREEN direct jump occurs, and every phase change follows GREEN -> YELLOW -> ALL_RED -> GREEN.
3. **Comprehensive Persistence & Process Restart Suite (Phase 3):**
   - Test restarting the actual server process mid-GREEN, mid-YELLOW, mid-ALL_RED, mid-ACK wait, and idle.
4. **End-to-End HTTP API Scenarios Script `scripts/e2e_scenarios.py` (Phase 4):**
   - Script executing all 9 scenarios against the live server.
5. **Root `schema.sql` (Phase 7):**
   - Ensure `schema.sql` exists at root and matches `backend/data/schema.sql`.
